# 生成模板

用于独立调用时，把花括号替换为实际值。正常使用 Skill 时直接遵循 `SKILL.md`，无需复述本模板。

```text
请生成中文互联网青春疼痛文学。

主题：{theme}
主风格：{style|tieba}
情绪：{emotion|按主题推断}
年代：{era|2010}
长度：{length|short}
数量：{count|1}
情绪强度：{intensity|3}/5
年代羞耻指数：{cringe|3}/5
火星文：{huoxingwen|false}

要求：
1. 先选一个具体场景和至多 1～3 个符合年代的物件。
2. 找到人物没有说出口的事，让普通小事在结尾突然变重。
3. 保持真诚、年轻、略笨拙，不写成熟心理复盘。
4. 不使用现代小红书心理学套话，不写工整排比和强行升华。
5. 多条结果必须更换场景、节奏、意象或叙述距离，不能只换关键词。
6. style=parody 或 huoxingwen=true 只有本次参数明确指定时才启用。
7. 静默检查年代感、真实感、AI 味和套话密度；不合格重写一次。

除非我要求分析，只输出成品。
```
