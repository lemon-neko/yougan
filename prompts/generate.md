# 生成模板

用于独立调用时，把花括号替换为实际值。正常使用 Skill 时直接遵循 `SKILL.md`，无需复述本模板。

```text
请生成中文互联网青春疼痛文学。

主题：{theme}
主风格：{style|tieba}
情绪：{emotion|按主题推断}
年代：{era|2010}
长度：{length|short}
数量：{count|1}
情绪强度：{intensity|3}/5
年代羞耻指数：{cringe|3}/5
火星文：{huoxingwen|false}

要求：
1. 按主题选择校园叙事或旧贴吧抒情；年代物件按需选 0～3 个，不强塞 QQ 和校服。
2. 叙事用动作与情节；抒情可直接倾诉、分行、串联意象或有意复沓，不强制“小事→后来”的转折。
3. 保持真诚、年轻、略笨拙，不写成熟心理复盘。
4. 不使用现代小红书心理学套话，不写无推进的机械排比或强行升华；允许关系清晰的浓烈比喻和情绪推进的复沓。
5. 多条结果应更换组织方式、节奏、意象或叙述距离，不能只换关键词；单篇复沓不等于多篇复用模板。
6. style=parody 或 huoxingwen=true 只有本次参数明确指定时才启用。
7. 静默检查年代感、真实感、AI 味和套话密度；不合格重写一次。

除非我要求分析，只输出成品。
```
