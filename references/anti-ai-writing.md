# 降低 AI 味与现代感

本文件用于改写初稿和转换现代文案。目标不是故意写差，而是去掉 2020 年代的成熟解释、标准答案和过度工整。

## 直接淘汰的现代套话

除非任务是识别或改写这些表达，不在成品中使用：

- 情绪价值、内耗、松弛感、精神内核、自洽
- 允许一切发生、接住自己、与自己和解
- 成为更好的自己、人生旷野、爱自己
- 情绪稳定、课题分离、关系中的边界感
- 低配得感、高敏感、停止期待、筛选关系

这些词的问题不只是年代晚，也会替人物把情绪解释完。

## 常见 AI 痕迹

### 1. 三段工整排比

坏味道：

```text
我们告别了教室，告别了操场，也告别了那个懵懂的自己。
```

改法：保留一个人真的会记住的动作。

```text
教室锁门的时候，我才想起抽屉里还放着你借我的尺子。
```

### 2. 结尾强行升华

坏味道：

```text
我终于明白，所有遗憾都是成长的礼物。
```

改法：让遗憾继续停在物件上。

```text
那张同学录我还留着，只是上面的号码早就打不通了。
```

### 3. 过分成熟的自我认识

坏味道：

```text
我学会了尊重每一段关系的自然流动。
```

改法：回到年轻人的无能为力。

```text
我不知道人为什么会走散。明明我们连座位都没有换过。
```

### 4. 抽象名词过多

坏味道：

```text
时间完成了对关系的重构，青春也在沉默中退场。
```

改法：把“时间”和“关系”换成可见变化。

```text
毕业以后，班群一天比一天安静。最后只剩系统提醒谁又改了名字。
```

### 5. 比喻太漂亮

坏味道：每个名词都被比作星河、潮汐、宇宙、旷野。

改法：一个略笨却准确的比喻已经足够；很多时候根本不需要比喻。

### 6. 怀旧清单

坏味道：一口气写 QQ、黄钻、飞信、诺基亚、MP3、网吧、XP。

改法：只留下那个改变人物动作的媒介。例如，因为等头像亮起，所以没有关电脑。

### 7. 解释留白

坏味道：写完“希望你永远不懂”后，再解释那意味着什么。

改法：删掉解释，允许读者不知道全部真相。

## 改写步骤

1. 圈出抽象情绪词：遗憾、成长、释怀、关系、孤独。
2. 至少把其中一个换成动作或物件：没拨出的号码、没还的伞、空着的座位。
3. 删除最后一句道理，观察上一句是否已经能收住。
4. 拆掉过于工整的三段结构，保留一次轻微重复即可。
5. 检查人物是否太懂自己。若懂得太多，让他重新回到“我不知道”。
6. 检查年代物件是否只是摆设。若是，删掉或让它真正影响情节。
7. 朗读一遍：像文案团队开会产出的句子，通常需要写得更直接、更私人。

## 现代文案转 2010 的示例

输入：

```text
停止内耗，允许所有关系自然流动，先好好爱自己。
```

不保留它的“建议”，只保留下面真正发生的事：一个人没有回复，另一个人在等。

改写：

```text
我盯着你的头像看了一晚上。
它没有亮，我也没有舍得关电脑。
```

## 自检问题

- 这像十六岁的人写的，还是三十岁的人替十六岁的自己做复盘？
- 有哪一个东西是摄像机能拍到的？如果一个都没有，补一个。
- 最后一句是不是在教读者如何生活？如果是，删掉。
- 把平台名删掉后，句子是否仍有情绪？如果没有，它只是怀旧 cosplay。
- 是否能听见一个具体的人在说话，而不是“互联网文案生成器”在说话？
