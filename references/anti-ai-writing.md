# 降低 AI 味与现代感

本文件用于改写初稿和转换现代文案。目标不是故意写差，而是去掉 2020 年代的成熟解释、标准答案和过度工整。

先判断是叙事还是抒情。抽象、分行、比喻、排比本身不构成 AI 味：年轻人也会直说孤独、认真夸张、反复吟咏。需要删除的是无推进的套话，不是所有修辞。

## 直接淘汰的现代套话

除非任务是识别或改写这些表达，不在成品中使用：

- 情绪价值、内耗、松弛感、精神内核、自洽
- 允许一切发生、接住自己、与自己和解
- 成为更好的自己、人生旷野、爱自己
- 情绪稳定、课题分离、关系中的边界感
- 低配得感、高敏感、停止期待、筛选关系

这些词的问题不只是年代晚，也会替人物把情绪解释完。

## 常见 AI 痕迹

### 1. 机械排比，不是所有排比

坏味道：

```text
我们告别了教室，告别了操场，也告别了那个懵懂的自己。
```

这句的问题是用三个泛泛名词替代真实心事，不是“排比”这个形式。叙事可保留一个人真的会记住的动作：

```text
教室锁门的时候，我才想起抽屉里还放着你借我的尺子。
```

抒情也可保留有推进的复沓（以下为原创示意）：

```text
我可以不问你去了哪里，
不问你为什么不回来，
可你总得告诉我，
该把这些没问出口的话交给谁。
```

判断重复是否有作用：第二次是否比第一次更深、更退缩或更矛盾？若只是凑足三项才算工整，就删减；若在积累执念，不必抹平。

### 2. 结尾强行升华

坏味道：

```text
我终于明白，所有遗憾都是成长的礼物。
```

改法：让遗憾继续停在物件上。

```text
那张同学录我还留着，只是上面的号码早就打不通了。
```

### 3. 过分成熟的自我认识

坏味道：

```text
我学会了尊重每一段关系的自然流动。
```

改法：回到年轻人的无能为力。

```text
我不知道人为什么会走散。明明我们连座位都没有换过。
```

### 4. 抽象分析取代了情绪

坏味道：

```text
时间完成了对关系的重构，青春也在沉默中退场。
```

问题在于分析腔和名词化，不在于提到了时间。叙事可换成可见变化：

```text
毕业以后，班群一天比一天安静。最后只剩系统提醒谁又改了名字。
```

直接抒情则可说：“我还喜欢你，连难过都不肯分给别人。”不需要再加课桌、QQ 或多年以后。能听清心事，比是否出现抽象词更重要。

### 5. 意象无关、不断换喻

坏味道：每个名词都被比作星河、潮汐、宇宙、旷野。

改法：让一个中心比喻延展，或直接说心事。旧贴吧式浓烈比喻可以保留，只要关系清楚、措辞可读。不能因为比喻漂亮或句子分行，就统一改成写实小故事。

### 6. 怀旧清单

坏味道：一口气写 QQ、黄钻、飞信、诺基亚、MP3、网吧、XP。

改法：只留下那个改变人物动作的媒介。例如，因为等头像亮起，所以没有关电脑。

### 7. 解释留白

坏味道：写完“希望你永远不懂”后，再解释那意味着什么。

改法：删掉解释，允许读者不知道全部真相。

## 改写步骤

1. 圈出抽象情绪词：遗憾、成长、释怀、关系、孤独。
2. 叙事把泛泛感受落到动作或物件；抒情则明确在对谁说、害怕什么或舍不得什么，不强制加实物。
3. 删除最后一句道理，观察上一句是否已经能收住。
4. 删掉没有推进的整齐句式；保留表达执念、递进或改口的复沓，不设“一次重复”的通用上限。
5. 检查人物是否太懂自己。若懂得太多，让他重新回到“我不知道”。
6. 检查年代物件是否只是摆设。若是，删掉或让它真正影响情节。
7. 朗读一遍：像文案团队开会产出的句子，通常需要写得更直接、更私人。

## 现代文案转 2010 的示例

输入：

```text
停止内耗，允许所有关系自然流动，先好好爱自己。
```

原句没有提供具体事件，以下是选择“等待”情境的一种原创转写，不是声称输入者确实经历过。也可以选择直接倾诉，不必每次生成相同的等头像故事。

改写：

```text
我盯着你的头像看了一晚上。
它没有亮，我也没有舍得关电脑。
```

## 自检问题

- 这像十六岁的人写的，还是三十岁的人替十六岁的自己做复盘？
- 叙事是否有动作？抒情是否有情绪指向或连贯意象？不要用“摄像机拍不到”否定所有抒情。
- 最后一句是不是在教读者如何生活？如果是，删掉。
- 把平台名删掉后，句子是否仍有情绪？如果没有，它只是怀旧 cosplay。
- 是否能听见一个具体的人在说话，而不是“互联网文案生成器”在说话？
