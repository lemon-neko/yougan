# 风格分类

按用户目的选择主风格。可以融合两个风格，但必须有一个主导；不要把九种风格揉成一团。

每个风格内都可以按主题选择“叙事”或“抒情”，这不是新参数。明确要求校园情节或 `story` 时保留事件推进；明确要求分行、倾诉、意象时走抒情路线；未指定时按核心心事选择，多条结果避免全部走同一路。

## STYLE 01｜贴吧句子吧（`tieba`）

- 形式：短句为主，常见一两句话，可独立成为签名；用户指定分行或较长长度时，不强行压成两句。
- 组织：可直接说心事、对“你”追问、自我否认、用一个比喻承载关系，也可以先写小事再下坠。
- 背景：通常不交代人物关系和前因后果。
- 节奏：短句、换行、突然停止。

适合：批量短句、截图文案、匿名遗憾。

避免：每条都用“后来”；每条都写“多年以后”；每条都必须靠反转；用复杂设定解释痛苦。分行抒情参考的是相邻旧贴吧文风，不把不同吧的样本统称为句子吧原帖。

## STYLE 02｜QQ 空间伤感日志（`qzone`）

- 形式：第一人称独白，100～800 字最自然。
- 时间：常在深夜回忆白天、毕业那年或已经失联的人。
- 语气：愿意承认“我以为、其实、直到”，偶尔重复，自我感很强。
- 结构：可以从回忆进入，也可以从“我还想问你”直接开始；独白可犹豫、反复、否认自己，结尾可停在细节、追问或未收回的一句话上。
- 分行抒情：允许同一意象贯穿多行、短语复现、情绪逐渐放大；每次重复应有作用，不强塞校园和平台。

允许有一点现在看来会尴尬的真心。不要写得像成年后的心理复盘。

## STYLE 03｜非主流个性签名（`signature`）

- 形式：通常 10～30 字；情绪密度高。
- 标点：可用省略号、破折号、单个问号；不要一行堆满符号。
- 语气：直接、绝对、带一点“全世界只有我懂”。
- 火星文：只有 `huoxingwen=true` 才启用，并保持可读。

适合：暗恋、被删好友、隐身等待、失恋。

## STYLE 04｜青春疼痛小说（`campus-fiction`）

- 形式：具体校园场景加大情绪，可从一个短段落延伸到小故事。
- 场景：教室、操场、晚自习、车站、校服、单车、雨、黄昏、毕业。
- 镜头：让人物做事；可停在当下，也可让叙述者多年后意识到那一刻的意义，不强制补“后来”。
- 核心：没说出口、没追上、没认出最后一次。

不要只列意象。至少让人物碰到、看见、忘记或错过其中一件东西。

## STYLE 05｜青春遗憾（`regret`）

- 形式：可短可长，是一种情绪组织方式。
- 题材：没表白、分班、转学、删除 QQ、换号码、未通过的好友申请、没有回的短信。
- 落点：可以是当年的小事多年后显得重，也可以当下就舍不得、后悔或不肯承认。
- 约束：不靠车祸、绝症、背叛等狗血情节制造强度。

可作为 `tieba`、`qzone` 或 `campus-fiction` 的副风格。

## STYLE 06｜时代互联网怀旧（`internet-nostalgia`）

- 形式：让旧媒介参与关系，而不是摆设。
- 写法：头像亮起意味着等待结束；留言板空着意味着某个人没来；耳机线断了一边意味着歌和回忆都偏向一侧。
- 数量：一次只用 1～3 个时代元素。
- 目的：旧物必须推动动作或承载“再也回不去”。

不要用百科式清单证明年代感。

## STYLE 07｜希望你永远不懂（`hope-you-never-understand`）

- 形式：一件普通、模糊、略反常的小事，换行后接“希望你永远不懂。”
- 信息：只给结果，不解释原因。
- 情绪：读者隐约能猜到等待、失联或自我保护，但无法完全确认。
- 约束：不要每次都写手机静音；前句应来自不同生活动作。

## STYLE 08｜伪深刻文学（`pseudo-profound`）

- 视角：十五六岁的人试图理解爱、永远、命运、成长和世界。
- 逻辑：似懂非懂可以，空泛胡扯不可以。
- 落地：可由小事引出，也可直接对爱、时间或孤独作笨拙判断；没有物件不等于失败，但读者应听得出人物究竟在怕什么、舍不得什么。
- 收束：结论可绝对、幼稚、好看，但不要像论文或成熟人生建议。

## STYLE 09｜青春疼痛 × 抽象（`parody`）

- 仅在用户明确要求时使用。
- 前半段认真复制疼痛文学的节奏，后半段用现实、技术或误会完成降落。
- 反转要短，不解释笑点。
- 不用网络热梗堆砌替代结构。

## 风格融合

优先用“载体 + 情绪组织方式”融合：

- `qzone + regret`：长独白可用旧物、未说完的话或反复追问收住。
- `campus-fiction + internet-nostalgia`：现实校园与线上等待互相照应。
- `tieba + pseudo-profound`：短句或分行得出笨拙而绝对的判断，不必都先讲事后总结。
- `signature + hope-you-never-understand`：压缩到一条签名，但保留模糊。

不要融合：

- 正常疼痛模式与 `parody`，除非用户明确要反转。
- 高浓度火星文与长篇故事；可读性会崩溃。
- 每条不同风格却不给区分；会让一组结果失去整体年代感。
