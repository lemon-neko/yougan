# 审美：解释选择，而不是宣布高级

## 从效果倒推形式

先问作品让谁在什么场景里读到、希望留下什么感觉。安静的私人书信和路边三秒可读的海报，评价标准不同。好看不等于装饰多，克制也不是唯一正确的风格。

| 观察位置 | 判断方法 | 可尝试的动作 |
| --- | --- | --- |
| 细节 | 换成任何人都成立吗？ | 保留一个只有此场景才有的动作 |
| 节奏 | 每句话是否同样长、同样重？ | 朗读，给关键处一次停顿 |
| 意象 | 比喻之间有没有关系？ | 保留最能承重的一组，删去抢戏的意象 |
| 留白 | 读者已经能感到的地方是否又解释一遍？ | 试着删掉总结，比较余味 |
| 视觉层级 | 第一眼与第二眼分别看到什么？ | 调整尺寸、位置和明暗关系 |
| 形式适配 | 载体是否支持这种密度？ | 海报减信息，书信保留自然呼吸 |

## 一次具体打磨

初稿：“今天很开心，我觉得整个世界都充满了希望。”
已知素材：“窗台上的豆苗长出了第二片叶子。”
改稿：“豆苗长出第二片叶子了。我把花盆往里挪了挪，给它腾地方。”

改稿用动作承载开心，适合偏含蓄的日记；若用户要大声庆祝，原来的直接表达也有价值。不能把此改法推广成“永远不要直接说情绪”。

## 赏析的最小单位

指认一个具体选择 → 描述阅读效果 → 说明取舍 → 给一个可试的局部变化。
例如：“‘嗯，收到’把对白压得很短，与前面的长等待形成落差。若改成热烈回应，会削弱距离感；如果目标就是庆祝重逢，则可以这样改。”

只引用必要短片段。不给未见过的作品编造镜头、台词或作者意图。练习可以是同一场景写长短两版、替换一个视角、删去最后一句再比较，不把作品统一打磨成一种腔调。
