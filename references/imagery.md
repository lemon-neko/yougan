# 意象库

意象是动作的落点，不是关键词装饰。每篇先选一个主意象，最多再选两个辅助意象。多版本要轮换感官、空间和动作。

## 校园

| 意象 | 可发生的动作 | 容易承载的情绪 |
| --- | --- | --- |
| 教室 | 换座、清空、锁门、最后一次回头 | 分班、毕业、告别 |
| 黑板 | 倒计时、值日生擦掉名字 | 时间、消失 |
| 吊扇 | 转得很慢、吹乱试卷 | 夏天、发呆、暗恋 |
| 课桌 | 刻字、抽屉里遗留纸条 | 没说出口、怀旧 |
| 校服 | 借走、名字写在领口、毕业后压箱底 | 身份、青春 |
| 操场 | 广播、跑操、散场、空旗杆 | 远望、错过 |
| 广播站 | 点歌、念错名字、毕业广播 | 暗恋、尴尬、离开 |
| 晚自习 | 停电、传纸条、走廊罚站 | 秘密、陪伴 |
| 同学录 | 留错号码、只写“常联系” | 注定失联 |
| 楼梯转角 | 擦肩、等人、听见脚步 | 期待、落空 |

## 天气与光线

- 雨：伞只够一个人、公交玻璃起雾、鞋袜湿透、没听清最后一句。
- 夏天：蝉声、风扇、冰汽水、晒烫的栏杆、试卷粘在手臂。
- 黄昏：放学铃之后、影子变长、教室只剩半面阳光。
- 阴天：灯提前亮、照片颜色发灰、心事没有具体原因。
- 台风：停课消息、窗户震动、想见的人隔在城另一边。
- 初雪：课间挤到窗边、没能一起看完、第二天已经化了。
- 风：吹走草稿、掀起窗帘、让一句话听不清。

## 物品

- 耳机：只剩一边有声音、借出去没还、线缠在校服口袋里。
- MP3 / MP4：循环一首歌、容量不够、文件名乱码、电量耗尽。
- 校牌：照片不好看、毕业后仍夹在旧书里。
- 作业本：名字写得很认真、借抄、最后一页藏着一句话。
- 铅笔 / 圆珠笔：笔迹变淡、写到没墨、涂掉一个名字。
- 车票：揉皱、没舍得扔、日期比记忆更清楚。
- 雨伞：借了没还、两个人挤、颜色在人群里消失。
- 自行车：后座、掉链、放学绕远路、车棚里只剩一辆。
- 手机：按键磨白、短信草稿、换号、欠费、充电线接触不良。
- 纸条：传错人、被老师没收、折痕多年后还在。

## 网络

- QQ 头像：亮起、变灰、换掉、再也认不出。
- 个性签名：为一个人改、等一个人猜、很快又删掉。
- 留言板：踩空间、互相留言、某个固定头像突然缺席。
- QQ 空间：背景音乐、访问记录、上锁日志、相册权限。
- 好友列表：分组、删除、重新申请、备注变回网名。
- 在线状态：隐身对其可见、手机在线、离线留言。
- 聊天记录：重装系统后消失、导不出来、只剩截图。
- QQ 等级：太阳、月亮、星星；适合写当时对等待和资历的认真。
- 飞信 / 短信：免费消息、字数限制、草稿箱、陌生号码。

## 地点

- 公交站：错过一班、雨棚太小、路线后来改了。
- 火车站：站台广播、进站口、车票、没有追上的背影。
- 天台：晾晒的校服、上锁的门、城市灯光。
- 小卖部：零钱、冰棍、排队时站得很近。
- 网吧：机号、下线倒计时、烟味、账号记在本子上。
- 教室最后一排：看得到所有人，却常被忽略。
- 校门口：家长、摊贩、放学人潮、迟到的等待。
- 书店：教辅区、翻过的同一本书、夹在书里的纸。

## 感官轮换

为避免所有文本都像“看见旧物然后想起她”，轮换：

- 声音：放学铃、QQ 上线提示音、广播、风扇、雨打车棚。
- 触觉：晒烫的栏杆、湿校服、卷边纸条、冰凉车窗。
- 气味：粉笔灰、雨后操场、旧书、网吧、橡皮屑。
- 光：屏幕蓝光、黄昏、停电后的应急灯、头像亮起。
- 时间动作：等五分钟、错过一班车、删掉又重写、刷新访问记录。

## 反重复规则

- 同一组五条里，最多两条使用“雨、黄昏、灰色头像”中的同一个意象。
- 同一篇不要同时出现 QQ、人人网、飞信、贴吧、MP3、诺基亚来证明年代。
- 意象一旦出现，必须与人物产生动作关系。
- “梧桐、天台、黄昏”不是自动高级；没有动作时宁可删掉。
