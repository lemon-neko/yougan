# 旧互联网文化使用指南

目标是让媒介影响关系，而不是用怀旧名词装饰句子。以下是创作语境，不是精确产品史；指定年份时还要结合 [era-guide.md](era-guide.md)。

## QQ

可用机制：

- 头像亮起或变灰：把等待变成可见状态。
- 隐身、在线、离线：制造“明明在，却不敢出现”。
- 好友分组与备注：关系被偷偷命名，也可能在删除后失去。
- 个性签名：把不能直说的话放给某个人看，又假装写给所有人。
- 空间访问记录：反复确认某个人来没来；删除访问记录也能成为动作。
- 留言板：公开而笨拙的亲密，常以“踩踩”“要开心”掩饰真心。
- 背景音乐：进入空间自动播放，适合写某个人的页面多年没更新。
- 黄钻与装扮：可点到为止，适合写当时对一件小事过分认真。
- 等级：星星、月亮、太阳；适合友情、攀比或漫长在线时间。

不要默认把“特别关心”放入过早年份；如果年份边界拿不准，改用更稳定的“好友分组、上线提示、访问记录”。

## 百度贴吧与句子吧语境

- 内容常被脱离上下文转发，因此短句要能独立成立。
- 楼层、楼主、挖坟、精品贴等词只在帖子叙事真的需要时出现。
- 句子楼的感觉来自匿名、留白和可复制性，不来自强行写“楼主”。
- 长帖可以有“睡不着，随便写一点”的随手感，但不要模拟真实用户身份。

## QQ 空间日志

- 标题可以很简单，如“无题”“有些话”“写在毕业以后”，也可以不写标题。
- 正文允许轻微重复、时间跳跃、对“你”的单向说话。
- 可以出现“仅自己可见、锁起来、删了又重发”的动作，但不要每篇都用。
- 结尾适合落在一个仍未改变的小物件，不适合总结成长方法。

## 人人网 / 校内网

- 更偏同学实名关系、状态、照片、主页痕迹。
- 适合 2009～2013 左右的大学或高中毕业语境。
- 重点是“知道彼此后来在哪，却没有再说话”，而非完全失联。

## 飞信、短信与功能机

- 短信有字数和费用意识，删草稿、存号码、欠费与换号都能构成情节。
- 飞信适合免费联系、班级通知、毕业后失去使用理由。
- 诺基亚等功能机适合按键、短信草稿、低清照片和换号；不要让它承担现代 App 功能。

## MP3 / MP4、网吧与 Windows XP

- MP3 / MP4：歌曲文件、容量、电量、耳机线和传文件比产品品牌更重要。
- 网吧：下线倒计时、机号、临时登录、忘记退出，适合 2005～2010 的空间。
- Windows XP：桌面、开机声、重装系统、聊天记录消失；只在电脑确实参与情节时使用。

## 手机时代初期

2011～2013 可写触屏手机、手机在线、随手照片逐渐出现，但不要假定所有学生都拥有最新设备。旧手机、电脑 QQ 与新智能手机可以短暂共存，这种过渡本身就是年代感。

## 时代元素配额

- `one-line`：通常 0～1 个。
- `short`：1 个足够，最多 2 个。
- `paragraph`：1～2 个。
- `post` / `story`：最多 3 个主元素；重复出现同一元素比继续添加新元素更真实。

判断标准：删掉这个旧媒介后，情绪结构是否改变？若不改变，它可能只是怀旧贴纸，应删除。
