# 语言与节奏

这些结构是可选零件，不是固定模板。每篇只取少量，不要为了“像”而重复拼装。

## 常用起点

- 回忆进入：那天、那时候、我记得、我已经记不清、很多年以后。
- 误判进入：我以为、我们都以为、我一直觉得、我没想到。
- 迟来认识：后来、直到后来、原来、再后来。
- 假设进入：如果那天、如果我当时、要是那节课。
- 含糊进入：有些人、有些事情、其实、我不知道为什么。

一组多条内容时，让至少一半的文本不用上述词开头。可以从动作、物件、声音、天气或一句对白开始。

## 有效结构

### 小事 → 下坠

先写一个普通动作，第二句改变它的意义。

```text
他把借我的笔拿了回去。
我那时才发现，我们之间已经没有东西需要归还了。
```

### 当时 → 后来

当时不知道，后来才知道。第二段不要解释成长，只改变时间尺度。

```text
毕业照拍得太快，我连头发都没整理好。
后来我找了很久，也没找到一张我们单独的合照。
```

### 等待 → 无声结果

用刷新、停留、绕路、亮屏等动作写等待，结尾不给明确回应。

### 否认 → 暴露

嘴上说不在意，行为却反复确认。适合 QQ 空间、好友列表、公交站。

### 具体 → 伪深刻

从一个课桌、号码或车站得出略幼稚的“永远”结论。结论要像十六岁，不像哲学教授。

### 模糊动作 → 希望你永远不懂

第一句足够具体，却不说原因；第二句固定收束。不要补第三句解释。

### 疼痛铺垫 → 现实反转

仅用于 `parody`。反转越现实越好，不能用一段解释摧毁节奏。

## 句长与换行

- 短句：8～22 字最容易形成旧网文节奏，但不要硬数。
- 一长一短：长句讲记忆，短句负责落下。
- 换行：在时间转折、没有说出口或最后一个物件前换行。
- 段落：QQ 空间日志可以比现代编辑习惯更碎，但不要每句话单独成段。
- 留白：故事没必要交代人物后来去了哪里；不知道也是结局。

## 标点

- 句号：比逗号更能制造落差。
- 省略号：允许有年代感，`cringe` 越高使用意愿越高；一篇 1～3 次通常足够。
- 破折号：可用于突然承认，不要连续使用。
- 问号：适合年轻人的自问，不要连续三个。
- 感叹号：慎用；高强度也应靠内容，不靠一排标点。
- 引号：只在真的出现一句话、签名或留言时使用。

## 强度 `intensity`

- `1`：轻微失落，不下“永远”结论，像偶然想起。
- `2`：自然伤感，一个具体细节，一次时间落差。
- `3`：默认黄金年代，可出现“后来、再也、整个夏天”中的一个。
- `4`：情绪明显放大，允许把一件小事等同于青春的结束。
- `5`：绝对化、命运感、世界末日感；必须仍有具体场景，否则只剩空喊。

## 年代羞耻 `cringe`

- `1`：今天读仍自然；少用绝对词和省略号。
- `2`：略有旧网文节奏，但比较克制。
- `3`：典型 QQ 空间 / 贴吧语感；真诚而不躲闪。
- `4`：愿意写“我的世界、你的背影、整个青春”。
- `5`：可以像十年前锁起来的空间日志；直接、夸大、羞耻，但仍需原创、可读和有细节。

## 火星文开关

仅当 `huoxingwen=true`：

- 最多替换少量高频字，如“伱、莪、噯、囙憶”，或加入一个可读符号。
- 只点染标题、签名或关键短句，不把长文全部转换。
- 不随机插入难以识别的 Unicode，不伪造编码乱码。
- 内容先成立，再加年代表面；删掉火星文后仍应是一句完整的话。

可接受的轻度效果：

```text
莪把伱移出了分组，却没移出那年夏天。
```

不可接受：整句布满特殊符号，读者需要解码。

## 多版本差异矩阵

生成多条时，至少轮换其中三项：

| 维度 | 选择 |
| --- | --- |
| 时间 | 当下、第二天、毕业后、多年后 |
| 镜头 | 人物动作、旧物、天气、网络状态、地点变化 |
| 人称 | 我对你、我看她、我们、无明确对象 |
| 节奏 | 一句、两句反转、三句递进、短段落 |
| 情绪 | 想念、懊悔、等待、嫉妒、麻木、释而未怀 |
| 收束 | 不知道、没有回复、物件留下、地点改变、名字消失 |

不要让每条都成为“那天……后来……再也没有……”。
