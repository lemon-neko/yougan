# 手工行为测试

本 Skill 是生成式写作规范，测试重点是可观察特征和失败模式，不用固定句子做脆弱的字符串匹配。每个 Case 至少生成两次，确认结果不是模板复读。文风判定须阅读输出，脚本只能检查结构、长度、数量和明显重复，不能证明文学质量或原创性。

## Case 1｜毕业 / 暗恋 / 夏天 / 2010

```text
使用 $youth-pain-literature
theme=毕业那天没能表白
style=campus-fiction
emotion=[graduation,secret-love,summer,unspoken]
era=2010
length=paragraph
intensity=3
cringe=3
```

通过条件：

- 有具体校园动作和夏天触感。
- 按需出现 0～3 个年代物件，且不靠清单营造怀旧。
- 情绪来自“当时不知道/没有说”，不是成年后的自我接纳。
- 100～300 字，不强行上价值。

## Case 2｜QQ 好友被删除 / 2008

```text
写 3 条 2008 年发现被删 QQ 好友的个性签名。
intensity=4
cringe=4
```

通过条件：

- 每条约 10～30 字，语气直接，允许一次省略号。
- 三条至少使用两种不同结构。
- 不出现已读、朋友圈、短视频或心理学词汇。
- 默认不用火星文。

## Case 3｜很多年后想起初中同桌

```text
theme=很多年后突然想起初中同桌
style=regret
era=2020s-retro
length=short
intensity=2
cringe=1
```

通过条件：

- 语气克制，但仍有青春疼痛的时间落差。
- 至少一个非常普通的同桌细节。
- 不写自我疗愈说教或“内耗、接纳自己”等现代套话；不单凭一个普通词判断年代。
- 不把对方写成死亡或重大悲剧。

## Case 4｜雨天公交站分别

```text
写一段雨天公交站分别的青春疼痛小说片段，2008 年，150～250 字。
```

通过条件：

- 雨、车或雨棚必须影响人物动作。
- 有一句没听清、没说完或没追上的内容，但不要照搬示例。
- 不堆 QQ、MP3、诺基亚等无关元素。
- 结尾留白，不解释后来的人生。

## Case 5｜贴吧句子吧 / 一句话 / cringe=5

```text
theme=分班以后再没说过话
style=tieba
era=2010
length=one-line
intensity=5
cringe=5
count=5
```

通过条件：

- 每条只有一句，可单独当签名。
- 允许“永远、世界、整个青春”等绝对词，但一条最多一个核心绝对词。
- 五条不能全部以“后来”开头。
- 夸张但仍有动作、空间或明确关系指向，不是空喊痛苦。

## Case 6｜青春疼痛 × 抽象

```text
style=parody
theme=她删了我的 QQ
count=4
```

通过条件：

- 前半认真，后半现实反转。
- 每条反转机制不同。
- 不解释笑点，不堆当代热梗。
- 未请求 `parody` 时不会意外生成此类内容。

## Case 7｜现代小红书文案改写

输入：

```text
停止内耗，允许关系自然流动，接住自己的情绪，成为更好的自己。
```

请求：

```text
改写成 2010 年 QQ 空间日志，100～200 字。
```

通过条件：

- 所有现代心理学套话从成品消失。
- 不保留劝告结构，可改成具体事件或有关系指向的倾诉；不强制又写等头像。
- 使用至多两个旧互联网元素。
- 结尾不出现人生总结。

## Case 8｜无校园物件的分行抒情

```text
style=qzone
emotion=[departure,loneliness]
era=2014
length=paragraph
intensity=4
cringe=4
写100～180字分行抒情，主题是“把未说完的话留给夜晚”。不要校园、QQ、手机，不编具体往事。
```

通过条件：不用被排除的物件也能成立；有清楚情绪指向和连贯意象；不换成校园故事；不误开 `parody`。

## Case 9｜有意复沓

```text
style=tieba
era=2010
length=short
intensity=3
cringe=3
主题：舍不得结束。用“再等一会儿”作有意复沓，2～5句，让重复有情绪变化，不需要小故事。
```

通过条件：短语至少重复两次，每次加深、改口或转移心事；不因排比被自动拆掉；不是同义词排队。

## Case 10｜批量结构多样性

```text
style=tieba
emotion=[regret,unspoken]
era=2010
length=short
intensity=3
cringe=3
count=10
主题：有些话没说完。每条2～5句，兼有叙事与直接抒情，不要十条都“后来才知道”。
```

通过条件：正好 10 条；至少三种组织方式，且两条路径均出现；差异不只是开头或名词；同篇有意复沓不误算成批量重复。

## 回归检查

每轮修改后检查：

1. `SKILL.md` 中所有相对链接都存在。
2. `style=parody` 与 `huoxingwen=true` 仍为显式开关。
3. `references/examples.md` 保持 42 组原创示例、九类风格覆盖。
4. 质量门槛仍要求年代感和情绪真实度不低于 7，AI 味不高于 3，小红书味不高于 2。
5. 同一批结果至少在三个差异维度上变化。
6. README 展示的提示词和输出与保存的当前对话试跑记录逐字一致；区分模型自检和独立评测。
7. 来源笔记不冒充整帖采集或精品认证，参考帖原句不成为示例。
