# 行为测试与验证边界

五种能力各两个场景，每个场景两份输出，共二十次同助手行为试跑。没有独立模型调用或第三方评测。原始输出与逐次人工自查见 [当前试跑记录](runs/2026-10-13.json)，可执行约束见 [用例定义](cases.json)。结果为本次实现助手在读取新指令后作出的回应，集中写入记录，不伪称独立会话。

`python3 tests/validate_project.py` 检查结构、链接、展示一致性、指令指纹及数量、行数等客观约束；不能验证共情、事实忠实度或作品新意。记录中的 review 是人工自查，不是脚本判定。

## 场景与人工验收

### O01 · observe

朋友考上了喜欢的学校。我真的开心，但看到消息后关掉了手机。帮我梳理能写的感受，不要写成故事，也不要断言我嫉妒他。

### O02 · observe

我只记得雨停后闻到了湿纸箱的味道，没什么故事。帮我观察素材，只给细节与一个写作切口，不添加人物。

### I01 · ideate

朋友要搬走，我帮他封好最后一个纸箱。给三个实质不同的文字方向，不添加真实物品，不写长成稿。

### I02 · ideate

我想用一片叶子的影子做手机海报，只能自己拍照。给三个不同的视觉方向，每个都说明构图和感觉，不生成图片。

### C01 · create

第一次自己做饭，盐多了，但很开心。写四行轻快的诗，只用这些事实，不添加别人的反应。

### C02 · create

做一个虚构的纸船绕过水杯的桌面短片方案，只在一个房间，三格共十二秒，不出现人物。每格标清时间、景别、动作和声音，不生成视频。

### R01 · refine

打磨这句给朋友的短笺：“我说话笨拙得像没拧紧的瓶盖，想谢谢你听我说，可总说不明白。”必须逐字保留“笨拙得像没拧紧的瓶盖”，不添加经历，只给改稿。

### R02 · refine

改写：“豆苗长出第二片叶子了，我真开心，我感觉它真好。”保留“第二片叶子”和开心的意思，别加往事，不要写成伤感，只给改稿。

### V01 · review

赏析这两句：“雨停了。屋檐还在练习下雨。”结合具体词句解释效果，给一个练习，不重写整首，不猜作者生平。

### V02 · review

帮我赏析昨天看到的那个海报，我没贴图，也没有链接。

## 复跑与记录

在新会话中加载根目录 Skill 与相关指南，分别给出各用例，不提供旧答案。每个用例执行两次，保存实际输入与输出，注明生成环境和是否独立；人工检查事实边界、个人语气、方案差异与可执行性。运行记录中的 `instruction_files` 记录逐文件哈希，`instruction_sha256` 使用校验脚本的指纹算法。

指令更新后新增日期或带后缀的运行文件，更新 `current-run.txt`，不要覆盖过去输出或仅改旧指纹。编辑案例单独保存在 `examples.json`，不与试跑结果混用。无论是否通过结构检查，都不能声称作品获得审美、共鸣或原创性认证。
